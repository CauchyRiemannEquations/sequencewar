# Sequence War: Last Stand

수열 문제를 풀면서 병력을 모으고, 스테이지별 보스를 격파하는 HTML5 캔버스 게임입니다.

## 실행 방법

`index.html` 파일을 브라우저로 열면 바로 실행됩니다.

GitHub Pages에 올리는 경우에는 이 저장소의 모든 파일을 같은 위치에 업로드하면 됩니다.

## 조작

- 마우스 또는 터치 드래그: 사령관 이동
- 키보드 `A` / `D` 또는 `←` / `→`: 사령관 좌우 이동
- 하단 `⏸` 버튼: 일시정지 / 재개
- 보스전에서는 병사와 사령관이 자동으로 공격합니다.

## 게임 규칙

- 수열의 `?`에 들어갈 숫자를 보고 올바른 관문을 통과합니다.
  - 3스테이지부터는 규칙의 공차/공비가 숨겨지고, 가운데 항을 가린 문제도 등장합니다.
  - 스테이지가 오르면 계차수열, 피보나치 수열이 추가됩니다.
- 정답을 고르면 병력 증가, 무기 강화 보상을 얻고, 연속 정답 시 콤보 골드 보너스가 붙습니다.
- 오답을 고르면 병력을 잃거나 무기 레벨이 내려가며, 정답이 무엇이었는지 알려줍니다.
- 관문을 모두 통과하면 보스전이 시작됩니다. 총 10개 스테이지가 있습니다.
- 보스전 중에는 숫자 블록이 주기적으로 내려옵니다. 아군 사격으로 정답 블록을 부수면 일제사격으로 큰 피해를 주고, 오답 블록을 부수면 병력을 잃습니다. 블록을 쏘는 동안에는 그만큼 보스에게 화력이 덜 들어가는 것도 전략 요소입니다.
- 병력과 무기가 모두 가득 찬 상태의 정답 보상은 실드로 바뀌어, 보스전에서 피탄 1회를 막아줍니다.
- 패배해도 골드와 업그레이드는 유지되며, 같은 스테이지에 다시 도전할 수 있습니다.
- 진행 상황(골드, 스테이지, 업그레이드, 최고 기록/정답률/최다 콤보)은 브라우저에 자동 저장됩니다.

외부 CDN 의존이 없어 인터넷 연결 없이도 동작합니다.

- `styles.css` — 스타일
- `game.js` — 게임 로직
- `orbitron.woff2` — 숫자/영문 폰트
- `background.jpg`
- `commander.png`
- `soldier.png`
- `player-bullet.png`
- `boss-laser.png`
- `boss-stage-1.png` ~ `boss-stage-10.png`
